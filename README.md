# MicBoost

برنامه‌ی بوست حرفه‌ای صدای میکروفون با رابط کاربری تیره و مدرن (Gaming/RGB style).

## قابلیت‌ها
- بوست میکروفون تا ۳۰ دسی‌بل با لیمیتر نرم (بدون خش/کلیپ)
- نویزگیت قابل تنظیم
- حذف نویز هوشمند (AI Noise Reduction - Spectral Gating)
- اکولایزر ۷ بانده قدرتمند (±۲۴ دسی‌بل هر باند)
- خروجی همزمان به چند مقصد (میکروفون مجازی VB-Cable برای دیسکورد/تیم‌اسپیک/گیم + تست روی اسپیکر)
- ذخیره و بارگذاری پریست
- متر سطح صدا ورودی/خروجی زنده

## پیش‌نیاز اجرا روی ویندوز
برای این‌که صدای پردازش‌شده در برنامه‌های دیگر (دیسکورد، تیم‌اسپیک، گیم و ...) قابل استفاده باشد،
باید درایور میکروفون مجازی **VB-Audio Virtual Cable** نصب شود:
https://vb-audio.com/Cable/

بعد از نصب، در تنظیمات برنامه (دیسکورد/تیم‌اسپیک/گیم) میکروفون ورودی را روی
`CABLE Output (VB-Audio Virtual Cable)` قرار دهید. برنامه MicBoost صدا را روی
`CABLE Input` پخش می‌کند.

## اجرا از سورس (توسعه)
```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python -m app.main
```

## ساخت فایل نصبی/exe (روی ویندوز)
```bash
build_exe.bat
```
فایل خروجی در پوشه‌ی `dist/MicBoost.exe` ساخته می‌شود. (اختیاری: با Inno Setup می‌توان
یک نصب‌کننده‌ی واقعی .exe/setup هم از این خروجی ساخت.)

## ساختار پروژه
```
MicBoost/
├── app/
│   ├── main.py            # نقطه ورود
│   ├── audio/
│   │   ├── dsp.py         # موتور پردازش صدا (بوست/گیت/نویز/اکولایزر)
│   │   ├── devices.py     # مدیریت دیوایس‌های صوتی
│   │   └── engine.py      # استریم بلادرنگ
│   └── ui/
│       ├── main_window.py # رابط کاربری اصلی
│       └── style.qss      # استایل تیره/مدرن
├── build.spec              # تنظیمات PyInstaller
├── build_exe.bat           # اسکریپت ساخت خودکار exe
└── requirements.txt
```
